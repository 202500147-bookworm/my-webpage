핏데이 PWA 설치 안내

1) 압축을 풀고 index.html, manifest.webmanifest, sw.js, 아이콘 파일을 같은 폴더에 둡니다.
2) PWA 설치와 오프라인 캐시를 사용하려면 HTTPS 웹호스팅 또는 localhost에서 실행해야 합니다.
   파일을 더블클릭(file://)해서 열면 일반 웹앱으로는 작동하지만 PWA 설치/서비스워커는 제한됩니다.
3) 스마트폰에서 HTTPS 주소로 접속합니다.
   - Android/Chrome: 브라우저 메뉴 또는 '홈 화면에 설치' 선택
   - iPhone/Safari: 공유 버튼 > 홈 화면에 추가
4) 최초 접속 후 한 번 로딩하면 서비스워커가 앱 화면 파일을 캐시하여 오프라인에서도 열 수 있습니다.

데이터 저장:
- 기록은 브라우저 LocalStorage에 저장됩니다. 새로고침/앱 재실행 후에도 같은 브라우저 프로필에서는 유지됩니다.
- PC와 스마트폰 간 자동 동기화는 제공하지 않습니다. 기기별 저장소는 서로 별개입니다.
- 브라우저 데이터/사이트 저장공간을 삭제하면 기록도 삭제될 수 있으니 정기적으로 백업을 권장합니다.

포함 기능:
- 운동/독서/습관 탭과 항목 추가/삭제
- 항목별 완료 체크 및 숫자/단위 입력
- 날짜별 기록, 월간 달력, 월별 달성률 그래프
- PWA manifest, 앱 아이콘, service worker
